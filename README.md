# UniFlow — Graduate Studies Management System

نسخة مصححة ومحدثة لنظام إدارة الدراسات العليا، مبنية بـ PHP 8+ وMySQL وHTML/CSS/JavaScript.

## أهم الإصلاحات في هذه النسخة

1. إصلاح صفحة الطلاب ومشكلة البحث الناتجة عن تكرار placeholders في PDO/MySQL.
2. البحث في الطلاب والبرامج والمقررات والمشرفين يعمل بــ prepared statements متوافقة مع `ATTR_EMULATE_PREPARES=false`.
3. اتجاه الواجهة عربي RTL فعلي، مع الشريط الجانبي على اليمين وتصميم متجاوب.
4. اعتماد التخرج يتحقق من الخادم من ثلاثة شروط مستقلة:
   - الساعات المجتازة >= الساعات المطلوبة للبرنامج.
   - حالة الرسالة `DEFENDED`.
   - نتيجة آخر مناقشة `PASS` أو `PASS_WITH_CHANGES`.
5. زر اعتماد التخرج لا يظهر للطالب غير المستوفي، والخادم يرفض العملية حتى لو أرسل الطلب يدويًا.
6. صورة الطالب وصورة المشرف اختيارية، وتقبل JPG/PNG/WEBP حتى 2MB.
7. واجهة حديثة RTL مع Dark/Light mode، بطاقات، حالات، جداول، بحث، Responsive layout.

## التشغيل من الصفر

> `database/schema.sql` ينشئ قاعدة `uniflow_graduate` من الصفر. خذ نسخة احتياطية إذا كانت لديك بيانات مهمة.

1. شغّل MySQL على المنفذ `3308`.
2. استورد:
   - `database/schema.sql`
   - `database/seed.sql`
3. من مجلد المشروع شغّل:

```powershell
php -S localhost:8000 -t public
```

4. افتح:

`http://localhost:8000`

### الحساب التجريبي

- Email: `admin@uniflow.local`
- Password: `password`

### إذا كانت قاعدة البيانات موجودة ولا تريد حذفها

نفّذ `database/upgrade_existing.sql` لترقية قاعدة قائمة إلى حزمة الميزات والأمان الجديدة دون حذف البيانات.

## ملاحظة مهمة

تم فحص PHP syntax وJavaScript syntax ومسارات المشروع محليًا. اختبار CRUD الحقيقي على MySQL يتطلب تشغيل MySQL 3308 على جهازك؛ لذلك لا يتم الادعاء بأن قاعدة بيانات جهازك تم اختبارها من بيئة البناء.


## حزمة الإصدار المحسّن

أضيفت إدارة المستخدمين والأدوار والصلاحيات، سجل تدقيق موسع، السنوات والفصول، المستندات الآمنة، مركز الإشعارات، البحث الموحد، ملف الطالب، صلاحيات على مستوى السجل للمشرفين وأعضاء اللجان، انتقالات Workflow محكومة للبحث والرسائل، دعم المقرر المشترك بين البرامج، GPA وتقارير CSV، وقيود أمن الجلسات ومحاولات الدخول.

### متغيرات البيئة
انسخ `.env.example` إلى `.env` واضبط بيانات MySQL. لا تضع بيانات الإنتاج داخل Git.

### التكاملات الاختيارية
- `MAIL_FROM`: عنوان المرسل عند استخدام `mail()` لإشعارات البريد.
- `WHATSAPP_WEBHOOK`: Webhook داخلي/مزود خارجي لإرسال WhatsApp.

### اختبار
شغّل `php tests/smoke.php` ثم فحوص syntax الموضحة في `tests/README.md`. اختبار MySQL الحقيقي يجب أن يتم على بيئة MySQL 8+ مستقلة.
