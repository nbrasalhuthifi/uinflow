# الحالات الاستثنائية
# نظام UniFlow لإدارة الدراسات العليا

## 1. تسجيل الدخول

- إدخال اسم مستخدم غير موجود.
- إدخال كلمة مرور خاطئة.
- ترك اسم المستخدم فارغًا.
- ترك كلمة المرور فارغة.
- محاولة الوصول إلى صفحة محمية بدون تسجيل الدخول.
- محاولة مستخدم الوصول إلى وظيفة لا يمتلك صلاحيتها.

## 2. إدارة الطلاب

- محاولة إضافة طالب بدون رقم جامعي.
- إدخال رقم جامعي مستخدم مسبقًا.
- إدخال بيانات طالب ناقصة.
- محاولة تعديل طالب غير موجود.
- محاولة حذف طالب مرتبط ببيانات أكاديمية أخرى.
- إدخال بيانات غير صحيحة في الحقول المطلوبة.

## 3. القبول

- إنشاء طلب قبول بدون بيانات المتقدم الأساسية.
- إنشاء طلب قبول مكرر لنفس المتقدم.
- محاولة تعديل طلب قبول غير موجود.
- محاولة تغيير حالة طلب غير موجود.
- إدخال حالة قبول غير صحيحة.

## 4. الأقسام والبرامج

- محاولة إضافة قسم باسم مستخدم مسبقًا.
- حذف قسم مرتبط ببرامج أكاديمية.
- إضافة برنامج بدون ربطه بقسم.
- حذف برنامج مرتبط بطلاب أو مقررات.
- محاولة الوصول إلى قسم أو برنامج غير موجود.

## 5. المقررات والخطط الدراسية

- إضافة مقرر بدون بياناته الأساسية.
- إضافة مقرر مكرر.
- ربط مقرر ببرنامج غير موجود.
- حذف مقرر مستخدم في خطة دراسية.
- محاولة تسجيل مقرر غير موجود.
- محاولة إضافة مقرر مكرر إلى نفس الخطة.

## 6. تسجيل المقررات

- تسجيل طالب غير موجود.
- تسجيل مقرر غير موجود.
- تسجيل الطالب في نفس المقرر أكثر من مرة.
- محاولة التسجيل في مقرر غير متاح.
- محاولة حذف تسجيل غير موجود.

## 7. المشرفون

- إضافة مشرف بدون البيانات المطلوبة.
- محاولة ربط طالب بمشرف غير موجود.
- محاولة حذف مشرف لديه طلاب مرتبطون به.
- إنشاء علاقة إشراف مكررة.

## 8. الأبحاث

- إنشاء بحث بدون ربطه بطالب.
- إنشاء بحث بدون مشرف.
- إدخال بيانات بحث ناقصة.
- محاولة تعديل بحث غير موجود.
- محاولة حذف بحث مرتبط برسالة علمية.

## 9. الرسائل العلمية

- إنشاء رسالة بدون طالب.
- إنشاء رسالة بدون مشرف.
- إدخال حالة رسالة غير صحيحة.
- محاولة تعديل رسالة غير موجودة.
- محاولة حذف رسالة مرتبطة بلجنة مناقشة.

## 10. لجان المناقشة

- إنشاء لجنة بدون رسالة علمية.
- إنشاء لجنة بدون أعضاء.
- تحديد موعد غير صالح للمناقشة.
- إضافة عضو غير موجود.
- إضافة نفس العضو إلى اللجنة أكثر من مرة.
- محاولة تعديل لجنة غير موجودة.

## 11. إجراءات التخرج

- محاولة اعتماد تخرج طالب لديه متطلبات ناقصة.
- محاولة تنفيذ إجراء تخرج لطالب غير موجود.
- محاولة تغيير حالة تخرج غير موجودة.
- محاولة إنهاء إجراءات التخرج قبل استكمال المتطلبات.

## 12. المستندات

- محاولة رفع ملف غير صالح.
- محاولة رفع ملف بدون ربطه بالعملية المناسبة.
- محاولة الوصول إلى مستند غير موجود.
- محاولة حذف مستند غير موجود.
- محاولة مستخدم غير مصرح له الوصول إلى مستند محمي.

## 13. قاعدة البيانات

- محاولة إدخال سجل يحتوي على علاقة غير موجودة.
- محاولة حذف سجل مرتبط بسجلات أخرى.
- حدوث خطأ أثناء حفظ البيانات.
- حدوث انقطاع أثناء تنفيذ العملية.
- إرسال طلب يحتوي على معرف غير موجود.

## 14. الصلاحيات

- مستخدم يحاول تنفيذ عملية خارج صلاحياته.
- مستخدم غير مسجل يحاول الوصول إلى النظام.
- محاولة الوصول إلى بيانات مستخدم آخر بدون صلاحية.
- محاولة تنفيذ عملية إدارية بحساب عادي.

## 15. البحث

- البحث عن طالب غير موجود.
- البحث باستخدام قيمة فارغة.
- البحث بقيمة تحتوي على رموز غير متوقعة.
- عدم وجود نتائج مطابقة للبحث.

## 16. التعامل مع الأخطاء

يجب أن يعرض النظام رسالة واضحة للمستخدم عند حدوث خطأ، دون إظهار معلومات حساسة مثل:

- كلمات المرور.
- بيانات الاتصال بقاعدة البيانات.
- تفاصيل الاستعلامات SQL.
- المسارات الداخلية للملفات.
